1. ゲームの全体像

にゃんこ大戦争（The Battle Cats / 開発・運営: ポノス株式会社）は、左右に伸びた1レーンの戦場で、自城からネコを出撃させて敵城を破壊するタワーディフェンス系ストラテジー。

1.1 核心となる3つのループ

ループ 内容
バトルループ お金を貯める → 適切なキャラを適切なタイミングで出す → 敵城を割る
育成ループ XP・素材を稼ぐ → レベル/形態/本能を上げる → より難しいステージへ
戦力拡張ループ ガチャ・イベントで属性対策キャラを揃える → 対応できるステージが増える

1.2 本作の勝ち筋の本質

「敵の射程外から、有利属性の特性で殴り、壁で時間を買う」——この一文に集約される。 火力よりも先に、射程差・属性相性・妨害（止める/遅くする）を理解することが上達の最短ルート。

3. バトルの根幹システム

3.1 バトルの流れ

  1. 序盤（0〜30秒）: 安価な壁キャラ（ネコ、タンクネコ、ゴムネコ等）を出して敵を足止めしつつ、働きネコレベルを上げる
  2. 中盤: 低〜中コストのアタッカーで前線を維持し、お金を貯める
  3. 終盤（ボス出現後）: 貯めた資金を主力アタッカーに全投入。壁を全力生産して守りながら殴り切る

3.2 お金（所持金）システム

  • 敵を倒す／時間経過（働きネコ）で増加
  • 働きネコ: 画面下部でレベルアップ可能。レベルを上げるほど毎秒の収入とお財布上限が増える
  • お財布上限（所持金上限）は働きネコレベルで決まる。高コストキャラを出すには先に財布を育てる必要がある

重要な初心者の落とし穴: 所持金を全額使い切ると、壁が切れて一気に押し込まれる。常に壁1体分の余力を残すのが鉄則。

3.3 城（自城・敵城）

  • 自城のHPが0になると敗北
  • 敵城を攻撃するとボス出現（多くのステージで敵城HPが一定量削れた瞬間に強敵が湧く）
  • 敵城の残りHPが減ると敵の湧きパターンが変わるステージが多い（"城を叩く＝スイッチを押す"）

3.4 出撃コストと再生産

  • 各キャラに出撃コストと再生産時間（クールダウン）がある
  • 壁キャラは「安い・再生産が速い」ことが価値。ゴムネコ（第3形態）の再生産の速さが壁性能の基準になる
  • 高コストの主力（ネコムート、超激レア）は再生産が長く、死なせると穴が空く

3.5 にゃんこ砲

  • バトル中にチャージが溜まると発射できる自城の砲台
  • 序盤に無駄撃ちしない。ボス出現直後・敵の大群が押し寄せた瞬間に使うのが基本
  • 詳細は第10章

3.6 統率力・スタミナ

  • ステージ挑戦には統率力を消費。時間回復のほか、広告視聴で1日1回無料回復が可能
  • 統率力の最大値は「パワーアップ」の統率力項目で拡張

4. ステータスの読み方（上級者の共通言語）

項目 意味と実戦での効き方
体力（HP） 壁役の生命線。「打たれ強い」「めっぽう強い」と掛け算で実効HPが決まる
攻撃力 単発の火力。表記は総合値で、多段攻撃キャラは内訳が分かれる
DPS 攻撃力 ÷ 攻撃頻度（秒）。継続火力の指標。ボス削りの速度を決める
射程 最重要ステータス。敵より射程が長ければ一方的に殴れる（アウトレンジ）
攻撃頻度 次の攻撃までの間隔。短いほど雑魚処理・妨害の再発動が速い
攻撃発生（F） 攻撃モーションを開始してから実際に判定が出るまでのフレーム数。長いと敵にすり抜けられる／妨害を撃つ前に殴られる
KB（ノックバック）数 何回吹き飛ばされたら後退するか。壁は多いほど粘る／アタッカーは少ないと下がりやすい
速度 前線への到達速度。速すぎると壁より前に出て被弾する。敵感知時に最大29Fのめり込みが発生し得る
コスト 出撃に必要なお金
再生産 次に出せるまでの時間。壁は短く、主力は長い

4.1 実戦で見るべき複合指標

  • DPS × 射程: 高難度でのアタッカー評価はほぼこれで決まる
  • HP × 被ダメ軽減特性: 壁の「実効耐久」。打たれ強い持ちは表記HPの4〜5倍相当 ⚠️
  • 攻撃頻度 × 妨害確率: 妨害役の「拘束率」。頻度が短いほど止め続けられる

4.2 攻撃タイプ

タイプ 説明
単体攻撃 最前の1体のみ
範囲攻撃 射程内の敵をまとめて攻撃。量産の敵に強い
遠方攻撃 「〇〇〜〇〇の範囲」のみ攻撃。近くの敵には当たらない → 壁が必須
全方位攻撃 前後どちらにも攻撃可能。後ろに抜けた敵にも当たる
連続攻撃（多段） 1回の攻撃で複数回判定。攻撃力ダウン・妨害の付与機会が増える
波動 / 烈波 / 爆波 本体の攻撃とは別に飛ぶ追加判定（後述）

5. 属性（トレイト）完全解説

敵キャラには属性が設定され、味方の「〇〇に強い/超ダメージ」系特性が乗るかどうかを決める。属性理解＝攻略の8割。

属性 特徴 代表的な敵 基本対策
白い敵（無属性） 属性を持たない。特攻が乗らない わんこ、にょろ、ゴリさん、ジャッキー・ペン 特性に依存しない素の高火力が必要
赤い敵 序盤から登場。HP・攻撃力が高め ブタヤロウ、ゴマさま、ウサ銀、一角くん、悪の帝王ニャンダム 「赤い敵に強い/超ダメージ」持ち＋厚い壁
浮いてる敵 地上に接さず特殊な移動。長射程が多い カオル君、ぶんぶん先生、ガガガガ 「浮いてる敵にめっぽう強い」＋妨害で制圧
黒い敵 移動が速く連続攻撃持ちが多い。上級者向け 殺意のわんこ、シャドウボクサー、ブラッコ、ウルトラメェメェ 「黒い敵に打たれ強い」壁＋停止/遅くする
メタルな敵 通常攻撃は常に1ダメージ固定。妨害もほぼ無効 メタルカバちゃん、メタルサイクロン、メタルカオル君 クリティカル必須。水鉄砲（割合ダメージ）も有効
天使 攻撃力・妨害能力に優れる。中盤以降の壁役 天使ガブリエル、天使スレイプニール、断罪天使クオリネル 「天使に超ダメージ」＋停止
エイリアン 未来編以降。バリア・ワープなど特殊能力 エイリワン、カーバチャン、ヤドカリー、イノヴァルカン バリアブレイカー必須。ワープ無効も有効。未来編お宝で弱体化
ゾンビ 撃破後に地中から復活する ゾンビワン、ゾンビゴリラ、チキランラン、亡者デブウ ゾンビキラー必須（復活を封じる）
古代種 「古代の呪い」で味方の特性発動を阻害 古代わんこ、ヘルゴリラー、シノシシ、ネコ仙人、エンシェントサイクロン 呪い無効＋「古代種に超ダメージ」
悪魔 悪魔シールド・呪い・複数攻撃など複合的 ダークドリル、ギルティペン、ベリアル 悪魔シールドブレイカー＋呪い無効
超生命体 高難度カテゴリ。専用特効が必要 超生命体系ボス 「超生命体特効」
超獣 高難度カテゴリ 超獣系ボス 「超獣特効」
超賢者 Ver.12.0以降。妨害効果を大幅カット レジェンドストーリー0の超賢者系 「超賢者特効」。通常の妨害役が機能しない

5.1 属性は重複する

1体の敵が「エイリアン かつ 浮いてる敵」のように複数属性を持つことがある。この場合、どちらの特攻も乗るため、対策キャラの選択肢が広がる。

5.2 特に事故が起きやすい3属性

  1. メタル — 火力キャラを何体並べても1ダメージ。クリティカル持ちを入れ忘れると詰み
  2. ゾンビ — 倒したつもりが復活して自城裏に出る。ゾンビキラー不在は敗北直結
  3. 古代種 — 停止・遅くする・ふっとばしが全部通らない。妨害編成が丸ごと死ぬ

10. お宝 完全解説

お宝は本作で最も費用対効果が高い強化要素。日本編・未来編・宇宙編の各ステージをクリアすると入手する。

10.1 仕組み（最重要）

  • 1地方（エリア）のお宝をすべて集めると効果が発動する
  • 品質は 粗悪（銅）< 普通（銀）< 最高（金） の3段階
  • 各章に同名のお宝が存在し、1章あたり100%、第1〜3章で合計300%まで加算される
  • 例: 「100%につき攻撃力+50%」のお宝なら、300%到達で攻撃力+150%
  • 集めたお宝の効果は、その章だけでなく全ステージ（レジェンド・イベント含む）に恒久適用される
  • 通常時のお宝ドロップ率は 約8〜13% ⚠️

つまり: 日本編第1〜3章のお宝をすべて金にするだけで、全キャラの攻撃力+150%・体力+150%相当が得られる。これはキャラのレベルを何十も上げるより効果が大きい。

18. ネコ道場・にゃんこ塔

18.1 ネコ道場

全ユーザーが獲得スコアを競うランキングコンテンツ。

ルール - 敵城は「木人城」＝破壊不可（HP表記は「?????」） - 木人城に一定ダメージを与えるごとに次の敵集団が出現する - 敵を倒すとスコアが加算される。ただしお金は一切もらえない（時間経過でのみ増加） - タイムアップ、または自城を落とされると終了 - 敵城の攻撃は即死級。生き残り特性持ちかメタル特性持ち以外は耐えられない

  1. 敵編成を確認（ステージ情報／攻略サイト）
  2. 主要な敵の属性を洗い出す → 特攻が乗るアタッカーを選ぶ
  3. 敵の最長射程を確認 → それを上回るアタッカーがいるか
  4. 厄介な特性を確認（バリア／シールド／ワープ／古代の呪い／波動）→ 対応する無効・ブレイカーを入れる
  5. 壁で残り枠を埋める
  6. 1段目にコンボが成立するように並べ替える

27. 実戦テクニック集

27.1 資金管理

  • 働きネコを先に上げるか、キャラを先に出すかの判断がステージの成否を決める
  • 敵の第一波が遅いステージ → 働きネコをMAX近くまで上げてから戦闘開始
  • 敵が即座に来るステージ → 壁を出しつつ少しずつ財布を上げる
  • 常に壁1体分の資金を残す（全部使い切ると壁が切れて崩壊する）

27.2 前線管理

  • 押し込み: 壁を出し続けて前線を敵城側へ押し上げる。長射程アタッカーが敵城を直接叩けるようになる
  • 引き込み: あえて敵を自城側へ引き寄せ、味方のにゃんこ砲・長射程の射程内で戦う
  • 生産停止: 前線が伸びすぎると敵の増援が一気に湧く場合、意図的に生産を止めて前線を下げる

27.3 KB（ノックバック）管理

  • ふっとばす特性は敵を強制後退させ、時間を大きく稼ぐ
  • ただし敵をにゃんこ砲や味方の射程外へ飛ばしてしまう逆効果もある。長射程アタッカー主体の編成ではふっとばしを控える判断も必要
  • 敵の「ノックバックカウンター」（KB時に反撃する敵）に注意 → 前線距離の調整で回避

27.4 射程管理（アウトレンジ）

  • 敵の射程 +1 でも上回れば一方的に殴れる
  • 遠方攻撃キャラは「攻撃できない死角」があるため、必ず壁とセットで運用
  • 速度が速すぎるアタッカーは壁より前に出て被弾する → 速度の遅い長射程を選ぶか、壁を厚くする

27.5 ボス戦の定石

  1. ボス出現前に資金を最大まで貯める
  2. ボス出現の瞬間ににゃんこ砲（かみなり砲なら停止、キャノンブレイク砲ならバリア破壊）
  3. 壁を全力生産して守りながら、主力アタッカーを一気に投入
  4. 妨害役を切らさない（停止・鈍足のループを維持）

34.2 統率力を無駄にしない小技

  • 開始10秒以内なら統率力を消費せずに戦闘を中止できる。左上の停止ボタンから離脱する → 出撃してから「この編成では無理だ」と気づいたときは、10秒以内に判断して抜ける
  • ステージ挑戦中にアプリを終了すると統率力を消費せずやり直せる、という挙動も知られている ⚠️ ただしコンティニュー不可ステージでは失敗扱いになるうえ、セーブデータ破損のリスクがあるため推奨しない
  • 広告視聴で1日1回、統率力を無料回復できる

34.5 データ引き継ぎ（機種変更）

  • タイトル画面 → オプション → 機種変更 → 機種変更の手続きを開始する
  • サーバーへセーブデータを保存をタップし、引き継ぎコードと暗証番号を発行する
  • OSをまたいだ移行（iOS ⇄ Android）にも対応している
  • サーバーの保管期間は3ヶ月。それを過ぎるとデータは復元できないため、発行したら早めに移行する

34.6 覚えておくと得をする仕様

  • 属性は重複する。「エイリアン かつ 浮いてる敵」なら両方の特攻が乗るため、対策キャラの選択肢が想像より広い
  • 移動速度が速いキャラは敵にめり込む。感知してから攻撃判定が出るまでに最大29フレームのズレが生じ、その間に殴られる ⚠️
  • メタルな敵への通常攻撃は常に1ダメージ固定。攻撃力を何倍にしても無意味で、クリティカルだけが解決策
  • 敵城を叩くのはスイッチを押す行為。多くのステージで敵城のHPが一定量減った瞬間にボスが湧く。準備が整うまで城を削らないのが基本
  • お宝は他の章にも効く。日本編で集めたお宝が、レジェンドでもイベントでも恒久的に効果を発揮する
  • にゃんコンボは1段目に置いたときだけ発動する。形態は問わないので、進化前でも進化後でも成立する
  • にゃんこメダルは消費されない。持っているだけでスロットが開く

34.7 名前の由来・ネーミングの遊び

  • ネコビタン（栄養ドリンク風）、ガマトト（探検隊のリーダー）、オトート開発隊（弟＝オトート）、ニャンピュータ（コンピュータ）など、既存の言葉をもじった造語が徹底されている
  • キャラ名・ステージ名にはパロディや語呂合わせが大量に仕込まれており、有志によるパロディ元の推測表が作られるほど。攻略に関係ない部分の作り込みが本作の魅力でもある
